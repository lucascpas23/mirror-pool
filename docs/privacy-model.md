# Privacy model

Announced cohort size is intent; observed cohort size is completed public activity. Behavioral similarity and synchronization may enlarge feature buckets, while dropouts and unique parameters shrink the effective set.

Transparent Registry exposes public one-time membership keys and timing. Merkle Cohort delays that public membership list by placing opaque signed tickets off-chain and only a root/count on-chain. The coordinator still sees every ticket. Neither backend hides activity wallets, common funding sources, transaction parameters, account age, RPC/network metadata, or long-term behavior. Merkle membership aggregation is not cryptographic wallet anonymity, transaction unlinkability, or a ZK proof.

Small cohorts are weak; Sybils can inflate announced size; last-revealer/release manipulation and coordinator delays remain risks. The deterministic evaluator reports entropy and classifier performance honestly, including unfavorable results. Synthetic improvement does not establish real-world protection.
