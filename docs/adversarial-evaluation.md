# Adversarial evaluation

The declared synthetic observer can use timing, instruction shape, fees, funding groups, amount buckets, and historical behavior. Deterministic traces compare uncoordinated/fixed-slot-like behavior, transparent synchronization, Merkle synchronization, cohort sizes 10/100/1,000, four strategies, narrow/wide windows, low/high dropout, and short/longitudinal periods. Six ablations remove one feature group at a time.

ROC AUC above 0.5 indicates useful linkage signal and is unfavorable; low normalized entropy, low minimum k, high uniqueness, false positives, and false negatives are all retained. The classifier is deliberately synthetic and must not be presented as a chain-analytics benchmark.
